# Vzorová firemná webstránka

Tento jednoduchý scaffold obsahuje základné HTML/CSS/JS súbory pre firemnú webstránku.

Obsah:
- `index.html` — domovská stránka
- `about.html` — o nás
- `services.html` — zoznam služieb
- `contact.html` — kontaktný formulár (frontend)
- `styles.css` — základné štýly
- `script.js` — malý JS pre formulár a rok

Spustenie:
1. Otvorte `index.html` vo webovom prehliadači.
2. Pre spracovanie formulára potrebujete backend — momentálne formulár len zobrazuje lokálnu správu o úspechu.

Ak chcete, prispôsobím dizajn, farby, texty a pridám reálne posielanie formulára.
